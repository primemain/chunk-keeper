# Chunk Keeper

A client-side Fabric mod for Minecraft 1.21.11 that keeps chunks on screen after the server tells your game to forget them.

It holds up to 16 extra chunks, within 4 chunks of you. Change MAX_KEPT and MAX_DISTANCE in ChunkKeeper.java to tweak it.

## Needs
- Fabric Loader
- Fabric API

## Download
Go to the **Actions** tab, click the newest build, and download **chunk-keeper** at the bottom.
